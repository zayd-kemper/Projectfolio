# Historical research and reviews

This directory preserves earlier research, design proposals, implementation notes, and audits. Their descriptions of the application are snapshots from their stated dates, not current setup instructions or proof of the present system's condition.

For current behavior, start with [setup](../SETUP_GUIDE.md), [deployment](../../DEPLOYMENT.md), and the application source.

## Reading the archive

- Security reports may describe findings that have since changed. Their current resolution status has not been revalidated as part of this documentation cleanup. Link findings to fixes and rerun relevant checks before marking them resolved; do not infer that they remain open or are fixed solely from the report date.
- Feature plans may contain work that is implemented, partly implemented, or still proposed. Check source and tests rather than interpreting an old checklist as the release status.
- The Discover research document contains historical external comparisons. Original citation markers were not usable outside their generating conversation, so they have been removed. Verify and supply primary-source links before presenting those comparisons as sourced research.
- The Auth migration runbook applies to an earlier populated-database cutover. It is not a fresh installation procedure.

Useful engineering history should remain available even when it records limitations or unsuccessful approaches. Local runtime caches and temporary tool state do not belong in this archive.
